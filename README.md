# pattern-b

パターンB掲示板アプリ（公開テスト v0）

サイト制作パッケージ「パターンB（フリーランス向け）」の掲示板型：
リットリンク風プロフィール（リンク集約）× ジャンル別スレッド掲示板。
投稿は自動削除されます（ゲスト1時間／ログイン会員8時間）。カードに残り時間を表示し、残り30分以下は赤字になります。

- 構成：Next.js 14 / Neon (Postgres) / Vercel
- 投稿の表示は expires_at > now() のものだけ（TTL が自動削除の実装そのもの）
- v0 の範囲：掲示板トップ／ジャンル別スレッド／プロフィール／ゲスト投稿（1時間）
- 会員ログイン（8時間側の投稿）は認証方式が未決定のため v0 では表示のみ
